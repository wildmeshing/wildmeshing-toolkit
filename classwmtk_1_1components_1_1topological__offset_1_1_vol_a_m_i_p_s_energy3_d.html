Detailed Description

The per-tet energy's AMIPS term for cells measured against a REFERENCE shape R, at one moving vertex x (use_rest_pose: a plastic cell against its stamped rest, TopoOffsetTetMesh::cell_is_plastic()): 

E(x) = weight * sum over the cells t of  vol_t(x) A_t(x)^3

A_t the AMIPS of F = E_t R^-1, E_t the edge matrix (columns q_k - x, the moving vertex first, positively oriented). With f = |F|_F^2 and g = det E_t: 

A = f / J^(2/3),  J = det F = g / det R,  vol = g / 6,  so  vol A^3 = c f^3 / g,
c = det(R)^2 / 6

– no determinant of F and no volume taken apart from the AMIPS. g is affine in x, so grad g is constant and hess g = 0; f is quadratic, grad f = -2 F s with s = R^-T 1, hess f = 2 |s|^2 I. The derivatives are exact: 

grad = c (3 f^2 grad f / g - f^3 grad g / g^2)
hess = c (6 f grad f grad f^T / g + 3 f^2 hess f / g
          - 3 f^2 (grad f grad g^T + grad g grad f^T) / g^2 + 2 f^3 grad g grad g^T / g^3)

A cell with g <= 0 makes the energy +inf and the step invalid. Against regular_rest() it is the same quantity CubedAMIPSEnergy3D computes from the edge lengths. value_of() is one cell's vol A^3 from its corners, which TopoOffsetTetMesh::tet_energy() reads for a plastic cell, so the rules and the smoother compare one number. Ported from archive/spenbert-offset (VolAMIPSEnergy<3>).
