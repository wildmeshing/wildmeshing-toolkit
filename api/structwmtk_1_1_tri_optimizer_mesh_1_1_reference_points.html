Detailed Description

The reference's input points, each with the labels of this mesh's input points it carries (bit j: m_point_names[j]): the 2D twin of TetOptimizerMesh::ReferencePoints, which says what anchor_feature_points() does with them. Set by the application before init, by set_reference_points().
