21 // Three bytes. The values are tiny -- a flag, a bbox side in [-1, 5], a class in {0, 1}, an
22 // orientation count that is +-1 or 0 almost everywhere -- but as int the struct was 12
23 // bytes, and the 3D meshes carry four of these per tet slot (the 2D ones three per triangle
24 // slot) in storage preallocated several times over: on the largest tetwild inputs that alone
25 // was most of a gigabyte. The class and the orientation share a byte as bitfields; both are
26 // int8_t so every compiler packs them together.
