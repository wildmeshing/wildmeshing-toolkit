225 // Per-primitive queries, for a caller that needs the distance d_i to each input primitive i
226 // on its own rather than to their union: each d_i is convex (the distance to a convex set),
227 // and the min over i is not, so a bound that rests on convexity needs the pieces.
228 //
229 // A primitive is one entry of the list given to init(), and its id is its index in that
230 // list: a triangle for Triangles3d, a segment for Edges3d and Edges2d -- including the
231 // degenerate (i, i) entries that stand for isolated points. squared_distance(), and
232 // nearest_point(), which returns the same squared distance, is the square of the min over
233 // all primitives of primitive_distance(), up to rounding: the BVH computes its own foot point
234 // with different arithmetic.
235 //
236 // Each query comes in the dimension of the init() that built the envelope: the 3D ones on
237 // Triangles3d and Edges3d, the 2D ones on Edges2d. Either asked of the other kind, or of an
238 // envelope no init() has filled in, throws rather than answering against the wrong copy of
239 // the input or dereferencing an empty BVH.
