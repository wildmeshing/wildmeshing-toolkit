Detailed Description

template<int N>
class wmtk::history::TrackedRecorder< N >

Records a tracked complex: some of the faces of a mesh, or some of its edges, which the mesh gives no ids of their own – the tracked faces of a tet mesh (N = 3), the tracked edges of a triangle mesh (N = 2).

The complex gets ids here: one for each mesh vertex on it, one for each face (triangle or segment), so the history is in the terms a TriMesh records in (History, replayed by BasicReplay) and a renumbering of the mesh changes nothing in it. At each commit an operation reports the tracked faces around it before and after, by mesh vertex ids. The recorder finds the edit that takes the one to the other – an edge split, an edge collapse, an edge swap – checks that it gives exactly the faces after, and records it; a change no edit fits it records as it is (EditKind::replace_faces), which a map cannot follow. A face keeps the corner order it had, through the edits' rules; one that only a replace_faces makes takes the order orient gives.

Features (History::features) are carried by the edits' rules alone; the mesh must keep them by the same rules. On curves a feature point keeps its vertex on the complex without any segment, so a collapse that removes one is recorded even when no segment changes.

Commits may come concurrently from operations whose regions do not overlap. They are serialised here, while each operation still holds its locks, so the order of the edits is a valid serial order of the run, as for BasicRecorder.
