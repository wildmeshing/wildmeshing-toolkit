SimWild

This component provides multiple tools (called operations in the JSON) to generate and modify tet meshes. Most functionality is also available in 2D, i.e., on triangular meshes.

Python

Every operation is a call wildmeshing.simwild(options[, meshes]) with the JSON options below, on files or in memory. See python/README.md for both routes, checkpoints, and the other tagged components.

Operations

All operations produce a .msh file as output. This file can be used as input for the next operation. The only exception is mesh generation, which takes surface or line meshes as input.

Operation Purpose JSON example
Mesh generation Tet/tri mesh from surface/line meshes simwild_double_sphere_notop_3d
remeshing Improve the mesh quality after other operations simwild_remeshing_2d
replace_tags Replace tags (or intersections of tags) with new ones simwild_replace_tags_3d
resolve_overlaps Split the overlap of two regions into the two regions simwild_resolve_overlaps_3d
