Detailed Description

template<class AppMesh>
class wmtk::ExecutePass< AppMesh >::QueuedCount

The count behind is_queued(): per key, the queued elements not yet tried or dropped. Striped, so threads queueing and finishing elements of different keys rarely meet on a lock; a single mutex (threading::concurrent_map) would be taken by every thread for every queued split.
