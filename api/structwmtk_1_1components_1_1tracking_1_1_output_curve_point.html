Detailed Description

A point on an application's output curves.

An application whose output is the curves themselves would name it by a segment of its output file. One whose tracked curves are edges of a triangle mesh (triwild), which are no element of the file, names it by two vertices of the mesh – the ends of a tracked edge – and barycentric coordinates in their order.
