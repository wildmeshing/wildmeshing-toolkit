Detailed Description

While one is alive on a thread, a curved bisector crossing a piece of a face (front_face(), front_face_derivs()) throws without being logged first; every other error is logged as before. "exact_swept"'s search model catches that throw and takes the ring cells' derivatives at that x instead (BandVolumeEnergy3D::set_swept()): there it is an expected outcome, not an error, and each throw would otherwise log a line with the face in hex floats.
