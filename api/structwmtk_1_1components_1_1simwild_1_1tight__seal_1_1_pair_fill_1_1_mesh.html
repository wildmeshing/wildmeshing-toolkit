template<int N>
std::function<size_t( size_t a, size_t b, double delta_a, double delta_b, std::vector<std::pair<size_t, size_t>>& children)> wmtk::components::simwild::tight_seal::PairFill< N >::Mesh::split

Splits the edge (a, b) where the linear function with values delta_a at a and delta_b at b, of opposite signs, vanishes: at fraction delta_a / (delta_a - delta_b) from a. Returns the new vertex, or size_t(-1) if the split is refused. Sets children to a (parent, child) pair for each cell the split made, from every cell on the edge, in a component or not.
