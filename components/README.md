# WMTK Components

Each directory here is a component: an algorithm built on the toolkit, configured by JSON options
that its `<name>_spec.json` documents and validates, and callable the same way from `wmtk_app`,
Python and C++. Components are maintained as part of the toolkit and tested in CI, with unit tests
and integration tests.

- The components, their tutorials and every option: https://wildmeshing.github.io/wildmeshing-toolkit/tutorials/
- Adding one: [Writing a component](https://wildmeshing.github.io/wildmeshing-toolkit/developer/writing-a-component/)
