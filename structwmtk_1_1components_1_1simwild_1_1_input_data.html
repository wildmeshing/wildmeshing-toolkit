◆ corr_input_vid

std::vector<int64_t> wmtk::components::simwild::InputData::corr_input_vid

The topological offset's correspondence handed on from an earlier offset (memory route, vertex field corr_input_vid): per row of V_input, the V_input row of the input-complex vertex it was split off from, -1 for none. Empty when the mesh has no such field. Only the offset reads it, and only with save_offset_correspondence (see its spec).

◆ F_envelope_labels

std::vector<uint64_t> wmtk::components::simwild::InputData::F_envelope_labels

Per row of F_envelope: the label bits of the input it came from, as the mesh's faces carry them (SimWildMesh::m_input_envelopes). Empty when F_envelope is not the inputs'.

◆ F_tagged

MatrixXi wmtk::components::simwild::InputData::F_tagged

Tagged faces of a tet mesh: rows of V_input, with one 0/1 column per face_tag_names entry. Empty when the mesh has no triangle block.

bool wmtk::components::simwild::InputData::has_input_history = false

A surface input with a history to record (history_output): the files as read and what became of them before the arrangement, and the input triangles each surface facet of the embedding lies on, by its corners' positions sorted. Empty otherwise.
