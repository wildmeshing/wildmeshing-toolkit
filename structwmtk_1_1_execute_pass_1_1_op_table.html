template<class AppMesh>
struct wmtk::ExecutePass< AppMesh >::OpTable

The registered operations by rank. edit_operation_maps is a std::map, so iterating it yields the names in lexicographic order and an operation's index is its name's rank: comparing ranks is comparing names, which is what keeps the queue order unchanged.
