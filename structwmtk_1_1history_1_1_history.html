Detailed Description

template<int N>
struct wmtk::history::History< N >

A complex and the edits it went through, in commit order.

Two kinds of complex, by the number of corners N of a face:

  • a surface (N = 3, SurfaceHistory), made of triangles;
  • a curve network (N = 2, CurveHistory), made of segments. Its positions are 3D like a surface's; a 2D application's have z = 0.

Replaying the edits from the snapshot (Replay.hpp) reproduces every later state, ids included, which is what a map between the first and the last state is built from. SurfaceHistory and CurveHistory name the two (Fwd.hpp).

Member Data Documentation

◆ features

template<int N>
std::vector<Feature> wmtk::history::History< N >::features

Features, which a map must take onto themselves, each with its vertices sorted. The edits carry them along by fixed rules, so only the snapshot lists them:

  • a surface's feature edges (label boundaries, say): a split feature edge leaves two feature halves, a collapse renames the removed endpoint's feature edges to the survivor, a swap never takes one;
  • a curve network's feature points (its junctions and ends, points of the input): a split makes none, a collapse of one renames it to the survivor. A feature point keeps its vertex alive without any segment: it may lie off the curves.

◆ input_vertex_ids

template<int N>
std::vector<uint64_t> wmtk::history::History< N >::input_vertex_ids

The id the mesh the history starts from gives each vertex of the first state – for a history that starts at a tet mesh's tracked surface rather than at input files, so that a point on it is named by the mesh's three vertices, as output_vertex_ids names one on the last. Empty when the first state is the input files' faces, as read.

◆ output_vertex_ids

template<int N>
std::vector<uint64_t> wmtk::history::History< N >::output_vertex_ids

The id the application's output gives each vertex of the last state, kNoVertex for one it does not write – for an application whose output numbers vertices its own way: a tet mesh's, whose tracked surface is no element of the output, so a point on it is named by the output's three vertices; a triangle mesh's, whose tracked curves are named by two. Empty when the last state's ids are the output's own, as a TriMesh application's are.
