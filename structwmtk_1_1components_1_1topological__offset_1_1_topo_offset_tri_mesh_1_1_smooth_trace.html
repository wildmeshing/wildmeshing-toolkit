Detailed Description

Why smoothing refused a vertex, one counter per site where it can say no.

The base's SmoothRejectCounters only sees the vertices that reach TriOptimizerMesh::smooth_after(), which for the offset is the INTERIOR ones – an offset-boundary vertex is placed by project_offset_vertex() and never touches them. So the whole offset boundary, the part that actually carries the distance error, is invisible in the base's "accepted N | rejected: ..." line. These counters cover every site on both paths.
