Detailed Description

Records a tracked surface: a triangle complex made of some of the faces of a mesh that gives them no ids of its own – the tracked faces of a tet mesh.

The surface gets ids here: one for each mesh vertex on it, one for each face, so the history is in the terms a TriMesh records in (SurfaceHistory, replayed by Replay) and a renumbering of the mesh changes nothing in it. At each commit an operation reports the tracked faces around it before and after, by mesh vertex ids. The recorder finds the edit that takes the one to the other – an edge split, an edge collapse, an edge swap – checks that it gives exactly the faces after, and records it; a change no edit fits it records as it is (EditKind::replace_faces), which a map cannot follow. A face keeps the corner order it had, through the edits' rules; one that only a replace_faces makes takes the order orient gives.

Commits may come concurrently from operations whose regions do not overlap. They are serialised here, while each operation still holds its locks, so the order of the edits is a valid serial order of the run, as for Recorder.
