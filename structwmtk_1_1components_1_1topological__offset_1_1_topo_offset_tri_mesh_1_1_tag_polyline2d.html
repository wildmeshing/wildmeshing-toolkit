Detailed Description

The per-tag boundary polyline, with the adjacency an arclength walk needs.

The same segments m_tag_envelopes[tag] was built from, in the same indexing, so SampleEnvelope::nearest_point_feature()'s feature_id (a polyline vertex index when on_corner, else a segment index) indexes straight into these. Built once beside the envelopes, from the input partition, and never rebuilt – the envelope is a tube around this curve, so the two must not be able to drift apart.

The component keeps its own copy because SampleEnvelope's arrays are protected and this mesh does not subclass it. at_vertex answers what the envelope cannot: which segments meet at a polyline vertex. Where three or more meet the walk stops, the continuation being ambiguous.
