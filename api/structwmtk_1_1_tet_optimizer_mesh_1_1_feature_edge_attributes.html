Detailed Description

Per-edge curve tags: which kinds of input curve this tet edge tiles.

One bit per KIND of curve, because each kind is held to its own tube (see tagged_edge_envelope()), and one edge can tile two kinds at once:

  • feature: the input feature curves the application was given, held by m_feature_envelope;
  • order2: the input's order-2 edges the application holds (holds_order2_edge()), held by m_order2_edge_envelope; set by tag_order2_edges(). An edge with any bit set is TAGGED, and the operations treat every tagged edge alike – propagated through split, collapse and swap, never removed by a swap, order-2 substructure for the link condition. Only the tube it is held to, and vertex_has_feature_edge(), read the kind.

Within a kind the tag is a union: which curve an edge belongs to is not carried through the optimization, and the kind's edges are held by one tube around all its curves. Tracked faces are different: each carries its input set (SurfaceTagAttributes::input_set()) through every operation and is held to its own inputs' envelopes, because one envelope around every input let a solid's boundary ride a sheet crossing it – measured, 12 faces up to 3.61 eps off the solid – and an audit at the end can find that but not prevent it. Curves are expected to follow the faces once two of them close together can be measured drifting the same way.

InputSet wmtk::TetOptimizerMesh::FeatureEdgeAttributes::m_feature_inputs = 0

Per kind, the inputs whose curves of that kind this edge tiles, bit i for input i, as a tracked face carries the inputs it lies on (SurfaceTagAttributes::input_set()): the input_edges file for feature, the inputs of the tracked faces at the edge for order2. The edge is held to those inputs' tubes (tagged_edge_leaves_tube()); an empty set falls back to the kind's union tube.
