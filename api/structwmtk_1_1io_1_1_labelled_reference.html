Detailed Description

A labelled reference (append_envelope_block()) as a receiving mesh reads it (read_labelled_envelope()): its triangles (2D: segments) on vertices of their own (dim columns), each with the bits of the receiver's labels it names, 0 for a row of labels the receiver lacks; in 3D its feature curves of the receiver's feature labels, an input edge per edge and label, edge_input that label's feature input.
