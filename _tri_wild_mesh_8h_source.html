46 // The curve network's 0-dimensional features are anchored by the base
47 // (TriOptimizerMesh's feature-point anchors), turned on in the constructor with
48 // m_feature_eps = the envelope eps. init_mesh fills m_feature_points from the
49 // arrangement's constrained edges: a vertex whose valence in that edge set is neither 0
50 // nor 2 is a feature -- valence 1 is an open polyline's endpoint, valence >= 3 a
51 // junction -- plus the input free points. Reading it off the arrangement rather than the
52 // raw input is deliberate: it is the network the optimizer actually starts from, so a
53 // junction the simplification was allowed to merge (which it may, with
54 // simplify_use_link_condition off) is correctly absent, and no provenance or
55 // position-matching plumbing is needed.
