Detailed Description

template<int N, typename Result>
struct wmtk::optimization::detail::LastEvaluation< N, Result >

The last point a pure function of x was evaluated at, and what it returned there, compared bit for bit. A Newton solve asks for value() about 32 times at about 5.5 distinct points – the line search and the stopping checks re-ask at the point just accepted – so returning the stored result for a repeat is the same answer for a fraction of the cost.
