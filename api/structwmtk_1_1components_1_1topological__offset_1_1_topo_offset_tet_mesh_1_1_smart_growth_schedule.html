Detailed Description

growth_mode "smart": which target to try next from the last converged distance, and what an attempt's result means. Pure, so it is unit-tested apart from the mesh.

From base (d_0, then each converged distance) the j-th try after j failures is at base + (delta - base) / 2^j: delta itself first. A success at delta is the end; a success below it becomes the new base (j and the failures start again); max_fails failures from one base give up.
