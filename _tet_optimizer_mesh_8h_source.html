1098 // ---- SWAP REJECTION INSTRUMENTATION (debug; see swap_reject_report()) ----
1099 // Every place a proposed swap can be turned down, counted. Added to find out why an offset
1100 // surface flip is never accepted; the counters cost one relaxed atomic increment on a path
1101 // that is already refusing the operation, and nothing reads them unless a caller asks.
1102 //
1103 // The refusals TetMesh makes itself, below every hook (the valence re-test, an open ring, a
1104 // face or edge that already exists, no allowed 4-4 / 5-6 case beating the current cells, out
1105 // of slots, a duplicate tet), were once visible here only as before_pass - after_enter. They
1106 // are now reported one by one through TetMesh::op_event(); see op_accounting_report(). The
1107 // per-turn line of this block still prints that difference as `connectivity`.
1108 //
1109 // Face swaps count their own reasons (face_*, and base_before / interior_hook / base_after /
1110 // after_cells on their path) in the per-kind table alone -- swap_reject_kind_only() -- so
1111 // swap_reject_report(), which has only ever described edge swaps, keeps meaning what it meant.
1112 enum class SwapReject : int {
1113 base_before, // TetMesh::swap_*_before said no
1114 base_after, // TetMesh::swap_*_after said no
1115 valence, // wrong incident-tet count for this swap kind
1116 bbox, // edge on the bounding box
1117 surface_not_allowed, // has surface faces and allow_surface_swap() is false
1118 feature_edge, // the swap would delete a tagged feature edge (it is the operated edge)
1119 prepare_flip, // prepare_surface_flip() refused (see the flip_* reasons)
1120 interior_hook, // swap_before_interior() refused
1121 flip_open_boundary, // flipping would change the surface's boundary loops
1122 flip_not_two_surf, // not exactly two incident surface faces
1123 flip_nonmanifold_edge, // more than two incident surface faces
1124 flip_cd_nonmanifold, // a surface face already sits on the new edge (c,d)
1125 flip_new_face_surface, // (a,c,d) or (b,c,d) is already tagged surface
1126 flip_app_refused, // swap_before_surface() refused (see the app_* reasons)
1127 flip_wrong_case, // 4-4 / 5-6: the retetrahedralization is not the one that makes
1128 // the surface diagonal (c,d), so this case is not the flip
1129 app_capture_label, // application: the swap ring spans two construction labels
1130 app_capture_tag, // application: the swap ring spans two cell tags
1131 app_fid_missing, // application: a face of the pair could not be found
1132 app_class_mismatch, // application: the two faces are different tracked surfaces
1133 app_mask_mismatch, // application: the two faces carry different boundary masks
1134 app_sag_raised, // application: the flip would raise the local sag
1135 after_inverted, // a created cell is inverted
1136 after_quality, // swap_quality_allowed() said no
1137 after_cells, // swap_after_cells() refused (see the app_after_* reasons)
1138 app_after_side_conflict, // application: two ring vertices of a new cell sit on two sides
1139 app_after_no_side, // application: a new cell holds no ring vertex to take a side from
1140 after_envelope, // a new surface triangle left the envelope
1141 face_tracked_surface, // face swap: the face is a tracked surface face
