2952 std::shared_ptr<polysolve::nonlinear::Problem> smoothing_extra_energy(
2953 const size_t vid) const override
2954 {

2956 // raw sum of AMIPS over the one-ring (AMIPSEnergy3D), as TetWild's does.
2957 if (tetwild_rules()) return nullptr;
2958 auto sum = std::make_shared<optimization::EnergySum>();

2960 // Before the march (repulsion_smoothing()) there is no front.
2961 if (is_repulsion_vertex(vid)) {
2962 sum->add_energy(repulsion_energy(vid));
2963 return sum;
2964 }
2965 if (vertex_carries_offset_term(vid)) {
2966 sum->add_energy(front_energy(vid));
2967 } else if (!vertex_is_held_on_input(vid)) {
2968 // E's band term moves with this vertex too -- except a vertex held on the input.
2969 // There d = 0 at the vertex and d has a kink: the term's slope along the input's
2970 // normal jumps across the surface, and its curvature there is 0 (or ~1e10 near an
2971 // input edge), so the Newton step along the normal is set by AMIPS alone and lands
2972 // far off; the projected step then discards the normal motion anyway. MEASURED
2973 // 2026-10-09, cube, serial, 3 turns: with the term these solves took 24.6 Newton
2974 // iterations and ~20 line-search trials per iteration (72% of the smoother's value
2975 // calls), without it 3.9 and 1; 19.3 s -> 11.3 s. E still guards the move:
2976 // smooth_vertex_under_energy() vetoes on the ring's sum of tet_energy().
2977 // Under "exact", not where it cancels (BAND TERM THAT CANCELS, tet_energy()): a ring
2978 // of band cells clear of the input's bisectors tiles the star of vid, so the term is a
2979 // constant, and its cells' exact integrals would add only work and their rounding to
2980 // every Newton step. The veto's own test (cancels_before in
2981 // smooth_vertex_under_energy()). Constant wherever the move can end, not only here: vid
2982 // is smoothed, so not on the domain wall (smooth_before()), and its ring closes around
2983 // it; the engine keeps no position that inverts a ring cell, so vid stays inside the
2984 // convex hull of its link; and the test reads the points only through their box, their
2985 // least side of each bisector polytope's planes, and min_P max d_P (d_P convex), none
2986 // of which a point inside that hull changes. So the test here certifies every position
2987 // the smoother can keep. "front_flux" and "exact_swept" leave the constant out by their
2988 // own forms
2989 // (band_volume_energy_at()). MEASURED (cube 1e-2 / 1e-4, 15 rounds, serial, two runs
2990 // each): 659 of 46,594 non-front solves had such a ring; at every one's end the
2991 // veto's test found it clear again, and every one was accepted; smoothing 7.7-7.9 s ->
2992 // 7.4-7.5 s.

2994 band_term_cancels(get_one_ring_tids_for_vertex(vid)))
