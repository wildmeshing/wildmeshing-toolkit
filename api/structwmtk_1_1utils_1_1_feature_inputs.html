Detailed Description

The feature curves and points a 3D application forces into its tetrahedralization (its curve and point inputs), as read.

One implementation for tetwild and simwild, so the two read, insert and hold them alike: read_feature_inputs() reads them, extend_bbox() grows the input bounding box over them, embed_features_input() marshals them for embed_triangles_in_tets(), and the mesh holds what the insertion made of them (TetOptimizerMesh::tag_feature_edges(), anchor_feature_points() with placed_point_vertices()).
