Detailed Description

The map between an application's input and its output, read from the tracking file the application wrote (its history_output option), in the terms its files use.

Built from the history alone; see SurfaceMap for how. A point that cannot be mapped – an input triangle the application dropped, a tracked face the output does not have – comes back with no face (kNoId), and the warnings of the call count it. Mapping never changes the object: several threads may map through one at once.
