Detailed Description

One envelope per input, and the containment and the pull of an INPUT SET (bit i = input i; see SurfaceTagAttributes::input_set()).

The invariant it serves: a tracked simplex stays within eps of every input in its set. containment() is therefore that input's own envelope for a one-input set, and the IntersectionEnvelope over the set's members for a larger one – containment only, by the contract above. pull() is the real member envelope a vertex is drawn toward, the set's most-violated member at the vertex's position, as topological_offset pulls a junction vertex: the containment check then enforces the whole set, one real envelope pulls at a time.

An empty set has no containment: a tracked simplex carrying one is an insertion or propagation defect, and throws rather than being held by some envelope it never covered.
