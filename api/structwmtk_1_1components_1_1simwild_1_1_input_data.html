std::vector<int64_t> wmtk::components::simwild::InputData::corr_input_vid

The topological offset's correspondence handed on from an earlier offset (vertex field corr_input_vid, on both routes): per row of V_input, the V_input row of the input-complex vertex it was split off from, -1 for none. Empty when the mesh has no such field. Only the offset reads it, and only with save_offset_correspondence (see its spec).

◆ diag

double wmtk::components::simwild::InputData::diag = -1

The diagonal eps_rel, eps_simplify_rel and length_rel are relative to (Parameters::init()): the inputs' own bounding box, the feature curves and points included, as in tetwild and triwild. -1 for a mesh input, whose own box is V_input's. Until 2026-11 SimWild used the box of the embedding, padded by a fifteenth of the diagonal on each side, for the optimizer, and the inputs' own for the simplification before the insertion: 1.22x apart on simwild_double_sphere_notop_3d, 1.42x on simwild_curves_2d.

◆ envelope_reference

std::optional<MeshData> wmtk::components::simwild::InputData::envelope_reference

An envelope input that is a labelled reference (io::is_labelled_envelope()), as tetwild, triwild and simwild hand theirs on: as given, for the run to hand on in turn while it holds to it. Its triangles (2D: segments) are then V_envelope and F_envelope, every row, and F_envelope_labels their labels' bits by name: a label is every bit of the mesh named as it (a face tag's, 2D an edge tag's, i; a region's, the face tags' count + j), 0 for a label the mesh does not have. Empty without one, and for an envelope without labels, held to as a whole as before the labels.

◆ F_envelope_labels

std::vector<uint64_t> wmtk::components::simwild::InputData::F_envelope_labels

Per row of F_envelope: the label bits of the input it came from, as the mesh's faces (2D: edges) carry them (SimWildMesh::init_label_envelopes(); 2D, SimWildMeshTri's). Empty when F_envelope is not the inputs'.

◆ F_tagged

MatrixXi wmtk::components::simwild::InputData::F_tagged

Tagged faces of a tet mesh: rows of V_input, with one 0/1 column per face_tag_names entry. Empty when the mesh has no triangle block. In 2D, the tagged edges (two columns) of the curve inputs or of a tagged mesh's edge block, and face_tag_names their edge tags' names. A row's vertex order is its orientation.

◆ feature_edge_names

std::vector<std::string> wmtk::components::simwild::InputData::feature_edge_names

The name of each feature input, bit i of a feature edge's input set: feature_ for input_edges file i, a tagged tet mesh's edge tags. Empty without feature curves.

◆ simplified_before_insertion

bool wmtk::components::simwild::InputData::simplified_before_insertion = false

Whether the input was simplified before the insertion (preserve_topology off). Around the input (envelope_reference "input") V_envelope is then the input as read, not what was inserted, and the mesh holds the input's own curves and curve points around the input (TetOptimizerMesh::InputCurves); around the simplified geometry it is the simplification.
