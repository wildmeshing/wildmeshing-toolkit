26 // ---- Stuck-element sizing refinement --------------------------------
27 // Trigger threshold: fire when the last iteration's improvement is small compared
28 // with the distance the max energy still has to cover, i.e. refine when
29 // (prev_max - max) <= stall_eps * (max - target).
30 // Equivalently: refine unless the mesh is on course to reach the target within
31 // about 1/stall_eps more iterations. 0 => only when it does not improve at all.
32 //
33 // The denominator is the remaining distance, not prev_max, and that is the whole
34 // point. Measured against prev_max, a mesh grinding down at a steady 1.3% per
35 // iteration toward a target far below clears a 1% bar every single iteration and so
36 // never looks stalled -- even though at that rate it needs on the order of a hundred
37 // more iterations and the operations have in fact deadlocked. The escape hatch then
38 // never fires, which is exactly the regime it exists for.
39 double stuck_refine_stall_eps = 0.1;
40 // Cooldown: after a refinement, skip this many improvement iterations before
41 // refining again, so the operations get full passes to act on the new sizing
42 // field before more refinement is added. 0 => may refine every iteration.
43 //
44 // 0 by default: measured over 468 triwild20k models, a cooldown of 1 costs ~13% wall
45 // time for exactly the same mesh sizes (identical median and p90 vertex counts). The
46 // idea that the operations need an idle iteration to act on the new field does not
47 // survive contact with the data -- the trigger already declines to fire while the mesh
48 // is converging, so a separate cooldown only delays the next escape.
49 int stuck_refine_cooldown = 0;
50 // Number of worst tets (by energy) whose neighborhoods are refined.
51 int stuck_refine_num_worst = 50;
52 // Graph rings around each worst tet's vertices included in the refinement.
53 int stuck_refine_rings = 3;
54 // Multiplicative reduction of m_sizing_scalar per refinement (0.5 => /2).
55 double stuck_refine_factor = 0.5;
56 // Lower bound on m_sizing_scalar. Much smaller than the old l_min/l floor;
57 // still far above the position-rounding scale so it stays numerically safe.

59 // Gradation cap for the monotone sizing smoothing: neighboring sizings may
60 // differ by at most this factor. The smoothing only ever *lowers* sizings
61 // (spreads refinement outward), never raises the refined values, avoiding
62 // sharp resolution jumps that make operations ill-conditioned.
63 double stuck_refine_gradation = 2.0;
64 // Force-split: when the max energy stalls, split each worst tet's longest edge
65 // once, bypassing the split length gate. This unsticks a sliver whose edges are
66 // too short to be split-eligible, WITHOUT touching the sizing field (which the
67 // *factor ratchet above still drives). Adds at most one split per worst tet per
68 // stall, so it does not bloat the tet count.
69 bool stuck_refine_force_split = true;
70 // When a split's rounded (double) midpoint would invert an incident tet, the
71 // split is normally rejected. If this is on, splits of edges that belong to
72 // the current worst-tet set (the seeds used by refine_sizing_around_worst)
73 // instead fall back to the EXACT rational midpoint (never inverts) and keep
74 // the new vertex un-rounded, so the worst region can still be refined.
75
76 // ---- Skip good regions ----------------------------------------------
77 // Only smooth vertices incident to a tet whose energy is >=
78 // skip_good_regions_margin * stop_energy. Smoothing a vertex surrounded by
79 // good tets does nothing, so skipping it is free (14-16x faster smooth
80 // passes). Only smoothing is gated: gating the topology/sizing ops
81 // (split/collapse/swap) starves the optimizer and blows up the element
82 // count, so those always run over the whole mesh.
83 bool skip_good_regions = true;
84 // Safety margin on the "active" threshold: a tet is active when its energy
85 // (cbrt of m_quality) is >= this fraction of stop_energy, so vertices near
86 // tets sitting just below the target are still smoothed.

189 box_min = min_;
190 box_max = max_;
191 diag_l = (box_max - box_min).norm();
192 if (l > 0)
193 lr = l / diag_l;
194 else

196 splitting_l2 = l * l * (16 / 9.);
197 collapsing_l2 = l * l * (16 / 25.);
