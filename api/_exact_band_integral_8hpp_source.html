381 // The front form (EXPERIMENTAL_band_volume_rule "front_flux"; Python prototype front_form.py,
382 // d_vertex.py, e_hessian.py, scratchpad front_form/ of 2026-10-13). Per feature k, in its
383 // local region, a field G_k with div G_k = d - delta, tangent to the region's planes and 0 on
384 // the input (d = 0):
385 // face G = (d^2/2 - delta d) W d = W.x - c, W = +-n on each side of its plane
386 // edge G = (d/3 - delta/2) (x - x_e) x_e the projection of x on the edge's line
387 // vertex G = (d/4 - delta/3) (x - v).
388 // On a band B made of cells, the divergence theorem cell by cell gives
389 // E(B) = int_B (d - delta) dV = sum over the boundary faces f of B of int_f G.n dA
390 // + sum over the cells t of D_t,
391 // D_t = int_t (d - delta) dV - oint_dt G.n dA: the jumps of G.n across the BISECTORS inside t
392 // (the sets where two features are nearest), 0 for a cell no bisector crosses. Every piece of
393 // the partition (as value()'s) is labelled with its nearest feature exactly: a member whose
394 // squared distance is not below another's anywhere on the piece is dropped (the exact range
395 // of the difference, a quadratic, over the piece); members that still cross must have a
396 // planar bisector (face-face, vertex-vertex, parallel or intersecting edge-edge), and the
397 // piece is split by it. A crossing pair with a curved bisector (face-edge, face-vertex,
398 // edge-vertex, skew edges) THROWS std::runtime_error naming the pair and the position:
399 // there is no approximation in this form (rule (a)'s bound is value()'s only).
400 //
401 // The offset side (class doc), as value(): a labelled part counts only on the offset side of
402 // its label's plane. On a labelled part the label is the nearest feature, whose plane meets it
403 // only where d = 0 (the pseudonormal theorem), so the side drops whole parts: a face's far
404 // side, and the edge and vertex parts beyond the input (MEASURED, the side cases' cells of
405 // the tests: 47 edge parts clipped by their side plane, every one dropped whole, none cut).
406 // Where G = 0 (on the input) the
407 // dropped parts carry no flux, so the identity holds with the side as without it. The
408 // Python prototype used the unsigned d (both sides of every face counted); the two agree on
409 // every part on the offset side, and constructed without a side this class is the prototype.
