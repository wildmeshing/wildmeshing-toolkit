Detailed Description

Collects the edits of operations that may commit concurrently.

A mesh appends while it still holds the locks of the operation it is committing, so two operations whose regions overlap append in the order they committed, and the order of the edits is a valid serial order of the run.

A mesh reports every vertex an operation wrote, which includes vertices it only read through non-const access. The recorder keeps the last position it saw for every vertex and drops the moves that leave a vertex where it was, and an edit that only moved vertices and moved none.
