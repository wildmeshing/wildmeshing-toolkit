Detailed Description

Boxes of the items 0..n-1, in a bounding volume hierarchy, for finding the items whose boxes meet a box.

Exact: a node's box is the componentwise min and max of its children's, and boxes are compared with <=, so no item whose box meets the query box is ever missed – only the tree's shape, which no answer depends on, is chosen in floating point (median splits of the box centres).
