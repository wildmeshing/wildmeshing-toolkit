Detailed Description

The map between a curve application's input curves and its output's, read from the tracking file the application wrote (its history_output option), in the terms its files use: Tracking's counterpart for curves (triwild).

Built from the history alone; see CurveMap for how. A point that cannot be mapped comes back with no segment and no vertices (kNoId), and the warnings of the call count it. Mapping never changes the object: several threads may map through one at once.
