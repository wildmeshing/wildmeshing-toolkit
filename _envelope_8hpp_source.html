207 // Per-primitive queries, for a caller that needs the distance d_i to each input primitive i
208 // on its own rather than to their union: each d_i is convex (the distance to a convex set),
209 // and the min over i is not, so a bound that rests on convexity needs the pieces.
210 //
211 // A primitive is one entry of the list given to init(), and its id is its index in that
212 // list: a triangle for Triangles3d, a segment for Edges3d and Edges2d -- including the
213 // degenerate (i, i) entries that stand for isolated points. squared_distance(), and
214 // nearest_point(), which returns the same squared distance, is the square of the min over
215 // all primitives of primitive_distance(), up to rounding: the BVH computes its own foot point
216 // with different arithmetic.
217 //
218 // Each query comes in the dimension of the init() that built the envelope: the 3D ones on
219 // Triangles3d and Edges3d, the 2D ones on Edges2d. Either asked of the other kind, or of an
220 // envelope no init() has filled in, throws rather than answering against the wrong copy of
221 // the input or dereferencing an empty BVH.
