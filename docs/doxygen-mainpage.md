# C++ reference

This is the reference of the toolkit's C++ classes and functions, generated by Doxygen from the
headers. The documentation — installation, tutorials, concepts and the developer guide — is at
https://wildmeshing.github.io/wildmeshing-toolkit/.

Where to start reading:

- wmtk::TriMesh and wmtk::TetMesh: connectivity, tuples, and the local operations.
- wmtk::ExecutionScheduler: how operations are scheduled and run in parallel.
- wmtk::MeshData and wmtk::io: meshes as components take and return them.
- The components, each in `components/<name>/wmtk/components/<name>/`.
