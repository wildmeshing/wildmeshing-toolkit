Detailed Description

Everything write_vtu() writes, as arrays: the mesh is read once, by gather_vtu_frame(), and write_vtu_frame() reads this and nothing else – so a debug frame's encoding and writing can run on another thread while the loop goes on (write_debug_frame()). Point arrays are vert_capacity() rows, indexed by vid; see gather_vtu_frame() for what each field is. tags[i] is named tag_names[i]; the last entry of tags is offset_tag.
