178 // Per-primitive queries, for a caller that needs the distance d_i to each input primitive i
179 // on its own rather than to their union: each d_i is convex (the distance to a convex set),
180 // and the min over i is not, so a bound that rests on convexity needs the pieces.
181 //
182 // A primitive is one entry of the list given to init(), and its id is its index in that
183 // list: a triangle for Triangles3d, a segment for Edges3d and Edges2d -- including the
184 // degenerate (i, i) entries that stand for isolated points. squared_distance(), and
185 // nearest_point(), which returns the same squared distance, is the square of the min over
186 // all primitives of primitive_distance(), up to rounding: the BVH computes its own foot point
187 // with different arithmetic.
188 //
189 // Each query comes in the dimension of the init() that built the envelope: the 3D ones on
190 // Triangles3d and Edges3d, the 2D ones on Edges2d. Either asked of the other kind, or of an
191 // envelope no init() has filled in, throws rather than answering against the wrong copy of
192 // the input or dereferencing an empty BVH.
