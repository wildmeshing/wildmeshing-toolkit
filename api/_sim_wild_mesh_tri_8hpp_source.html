404 // When set, split_adjust_position moves the new vertex to this function's zero on the edge,
405 // by 20 bisection steps between the ends (which must have opposite signs); if that inverts a
406 // child, the vertex goes back to the edge's midpoint. Set before split_edge(), cleared after,
407 // by seal_connected_components (tight_seal_topo, resolve_overlaps) and tight_seal_geom's
408 // march. m_edge_split_at takes precedence.
409 std::function<double(const Vector2d&)> m_voronoi_split_fn = nullptr;
410 // The vertex the calling thread's last split made, per thread as 3D's
411 // SplitTagCache::v_new: every thread of the parallel split pass writes it, and the serial
412 // callers (AnnotationsTri.cpp, TightSealGeom.cpp) read their own split's. One shared size_t
413 // was a write-write race, reported by ThreadSanitizer in 3 of 3 simwild 2D remeshing runs at
414 // 8 threads (2026-11-05).
415 wmtk::threading::enumerable_thread_specific<size_t> m_last_split_vertex;
416
417 // Where split_edge() puts the new vertex, if set: at `fraction` of the way from the end
418 // `from` to the other, exactly; rounded if that inverts no child, else kept exact and
419 // unrounded. It takes precedence over m_voronoi_split_fn. Set before split_edge(), cleared
420 // after; only tight_seal_geom's fill sets it.
421 struct EdgeSplitAt
