Detailed Description

The reference's input points (its point block), each with the labels of this mesh's input points it carries (bit j: m_point_names[j]).

Set, anchor_feature_points() centres the ball of each received input point on the nearest of them with its label in the ball, as it centres a curve end on the nearest of the reference's curve points (InputCurves): so a received point is held to the first component's, within one radius however many components came before, where anchored where it arrives it could end up to one radius further at every stage. Unlike a curve end, a point with none in reach throws, before anything runs: a simplification makes curve ends, but no component makes input points, so such a point is not this reference's. Unset – no envelope given – an input point is anchored where it is, as before. Set by the application before init, by set_reference_points().
